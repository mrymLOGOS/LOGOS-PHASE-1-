# معیار موفقیت — LOGOS-SL فاز ۱

پروژه مادر: **بنیاد LOGOS (Logos Foundation)**  
شاخه: **LOGOS-SL**

## داده
زیرمجموعه‌ای از دادهٔ عمومی رانندگی یا تصاویر با اختلال مصنوعی
(مثلاً نویز، تاری، برش، یا نمونه‌های OOD ساخته‌شده).
منبع دقیق در شروع آزمایش ثبت می‌شود.

## وظیفه
جدا کردن نمونه‌های عادی از نمونه‌های ناهنجار/OOD.

## خروجی ماژول LOGOS-SL
- `anomaly_score` ∈ [0, 1]
- `uncertainty` ∈ [0, 1]
- `decision` ∈ {OK, CAUTION, SAFE_STOP}

## Baseline
آستانه روی confidence مدل ادراک ساده یا فاصله از میانگین ویژگی‌ها
(جزئیات در دفتر آزمایش ثبت می‌شود).

## معیارهای اصلی
1. True Positive Rate (تشخیص درست ناهنجاری) بالاتر از baseline
2. False Positive Rate (هشدار کاذب) زیر سقف توافق‌شده در دفتر آزمایش
3. گزارش شفاف: جدول مقایسه baseline در برابر **LOGOS-SL** روی همان مجموعه تست

## موفقیت فاز ۱
وقتی روی مجموعه تست ثابت، **LOGOS-SL** از baseline در TPR بهتر باشد
و FPR از سقف ازپیش‌ثبت‌شده تجاوز نکند — با کد و جدول قابل بازتولید.
